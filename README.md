# Avinash Venkatraman — Portfolio

A terminal-aesthetic developer portfolio built with pure HTML, CSS, and JavaScript.
No frameworks, no build tools, no dependencies — just open and run.

## 🚀 Run Locally

### Option 1 — Python (recommended)
```bash
cd portfolio
python -m http.server 8000
```
Then open: http://localhost:8000/avinash_portfolio.html

### Option 2 — Just open the file
Double-click `avinash_portfolio.html` in your file explorer.
(Resume download works best via the Python server)

## 📁 Files
- `index.html` — the entire portfolio (self-contained)
- `README.md`              — this file

## 🥚 Easter Egg
Press `Ctrl + \`` anywhere on the page to open the hidden terminal.
Type `help` to see all commands.
